# rf-scope — Implementation Plan

> For agentic workers: superpowers:subagent-driven-development. Spec:
> `docs/superpowers/specs/2026-10-20-rf-scope-design.md` (read it first).
> Branch `rf-scope`. One fresh agent per task, reviewed.

## Global constraints

- CDC stays binary-only (KS/KR). The half's UART0 carries the same binary
  framing, interleaved with console text: the host parser resynchronises on the
  magic + length + CRC-8 (reuse the project's CRC-8 from `cdc_binary_protocol`).
- Trace compiled in, **off by default**, started by a command with a duration,
  **auto-off** at the end and on reboot. Zero cost when off: one branch on a
  flag in the hot path, nothing else.
- Hot path (radio owner, rx task): copy a fixed record into a static ring, never
  log, never block, never malloc; overflow increments a drop counter carried in
  the periodic record.
- Tracing must not change behaviour: no wake veto, no cadence change; records
  stop while the half sleeps (a periodic record says "asleep").
- Halves: nothing may leave a periodic wait < 30 ms (tickless rule, CLAUDE.md);
  the drain task blocks on the ring (notification), not on a poll.
- Host tool: Python 3, stdlib only except `pyserial` (curses TUI). Open only
  ports named on the command line, `fuser` check first, `dtr=rts=False` BEFORE
  open on the ESP-Prog. pytest for the pure parts.
- TDD for every pure function; shared vectors C ↔ Python pin the format.
- `./scripts/check.sh --fast` green per task; full six-board check before each
  firmware commit (`nix develop /home/mae/nixos-config#esp-idf --command
  ./scripts/check.sh`, `IDF_CCACHE_ENABLE=1`). English. Commits end with the
  attribution lines. No flash, no push, no tty access by agents.

---

### Task 1 — the shared record format (pure C + Python, vectors)

`main/comm/rf/rf_trace.{h,c}` (pure): record structs (emitter TX, receiver RX,
periodic), fixed-size little-endian encoding, the frame (magic, kind, len,
batch of records, CRC-8), decode with strict checks; the ring buffer (push,
pop batch, drop count, wrap) as a pure struct. Host tests first
(`test/test_rf_trace.c`). A C test (or generator) writes
`docs/contracts/rf_trace_vectors.json`; `tools/rf_scope/rftrace/codec.py`
decodes the same frames, `tools/rf_scope/tests/test_codec.py` (pytest) pins
them. Bite proofs. Commit.

### Task 2 — dongle side

Rx records in the dongle's receive path (`comm/rf/rf_rx_task.c` or where frames
are dequeued): emitter from pipe, seq, kind, RPD (register 0x09, read only when
tracing), FIFO depth, delivered to the fusion engine, duplicate. Periodic
record (counters, uptime). `KS_CMD_RF_TRACE` (0xBA): payload `start(duration_s)`
/ `stop` → KR ack; while on, unsolicited KR frames of cmd 0xBA carry batches.
Document in `docs/CDC_BINARY_PROTOCOL.md`. Pure parts tested (command payload
parse, duplicate detector, auto-off timer). Smoke item. Commit.

### Task 3 — half side (left and right)

Tx records in the radio owner after each transmission: seq (from the frame),
kind, result (TX_DS / MAX_RT), OBSERVE_TX ARC and PLOS delta, channel,
excursion flag. Periodic record (counters, drops, sleep state on the way in
and out of veille via a hook). UART0: framed batches out; a small RX reader for
`RF_TRACE start/stop` frames (no ASCII). Both halves (left relay + right
half_link). Pure parts tested. Check no tickless regression (no < 30 ms wait).
Smoke item. Commit.

### Task 4 — host tool

`tools/rf_scope/`: `capture` (both ports, start/stop commands, JSONL with host
monotonic times), `replay`, `report`; matcher (emitter, seq, epoch window,
dup, reorder, asleep), offset fit (median of matched pairs, jitter = MAD),
per-window statistics — pure and pytest-tested; curses TUI (per-half panels,
event list, sparklines). README with commands. Commit.

### Task 5 — channel scan

Dongle: `KS_CMD_RF_SCAN` (or a sub-command of 0xBA) sweeping channels with
radio 2 in RX, RPD sampled N times per channel; host `rf_scope scan` table.
Commit.

### Task 5b — stress generator and scenarios

Half: `RF_STRESS` command over UART0 (patterns: rate, burst, max, held; count or
duration; auto-stop), frames of a dedicated stress kind/flag sent through the
radio owner like real ones (same retries, same excursions). Dongle: count and
trace stress frames, DROP them before the fusion engine — host test proving the
engine never sees one, also with tracing off. Host: `rf_scope stress
--scenario burst|max|held|soak`, reports under load. Commit.

### Task 6 — bench (controller + Mae)

Flash dongle (CDC, app-only) and the left (ESP-Prog, MAC + fuser check first);
2-minute capture typing on both halves; stress scenarios burst/max/held, 1-hour soak; report; trace auto-off; sleep current
unchanged with trace off (HB slept=).
